# 設計紀錄

講座的四個重點成為四片三島群，中央六角講堂將「醫療改善症狀，營養打造健康」連成閱讀路線。主要互動是選主題、巡禮下一站，以及點中央主島看日期與講師。

配色與字級依使用者指定：米白、松綠、海水藍與金色。沒有模擬講師照片或虛構產品包裝，插畫是本地原創向量圖；Pro 可用時可依相同規格替換。無外部攝影素材或影片。

採 design-taste-frontend 的 app-screen 原則：清楚主操作、真實資料、可讀狀態與實際瀏覽器驗證。技能的 draw/inspect 腳本資源無法讀取，因此沒有虛構抽選方向或種子；依使用者明定方向，以 Playwright 與 axe 檢查正式頁面。

評閱重點：四組島嶼與中央講堂、右側 55% 產品卡、手機可點擊標籤、140% 字體、完整學經歷與三句導覽。醫學原文以文件歸屬呈現，不讓連線圖暗示臨床療效。

可重跑檢查與截圖由 `npm run test:browser` 產出於不提交 Git 的 `test-results/`。實體裝置效能與人工輔具體驗需另作實機驗證。

2026-11-14 最終驗證：正式建置、TypeScript、11 項資料／API／安全邊界測試均通過。Chromium 的 1440、768、390 像素流程涵蓋產品導覽、鍵盤分頁、140% 字體、語音控制契約、講師資料、知識館、離線導覽與合成 SSE 自動導航；總覽與 AI 對話框的 axe 檢查皆為零違規。另測一般動畫模式的鏡頭移動、返回總覽及講座主島入口。

截圖評閱修正了桌面總覽下緣標籤裁切、相鄰標籤重疊、地圖名稱的無障礙角色與次要文字對比。測試新增實際 DOM 矩形的裁切／重疊檢查。桌面產品卡保留主要閱讀空間；手機以可捲動版面與固定底部導覽維持大字級。
