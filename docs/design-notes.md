# 設計紀錄

本次依使用者明定的 iOS 18 方向改版：48px 浮動膠囊頂欄、米白玻璃閱讀面板、28px 圓角、原生蘋果字體與五鍵浮動工具列。使用者指定的玻璃材質、圓角與控制形式優先於設計技能的一般風格規則。

四個講座主題形成四片三島群，中央講堂開啟日期、地點與講師完整資料。群島改用固定正交鏡頭與暖日光，移除晝夜切換、自由旋轉、縮放、浮動與自動鏡頭旅行。閱讀欄在總覽與選取時始終保留相同空間；選取只改變光圈、連線與文字，不改地圖尺寸。Canvas 按需繪製，閒置時不持續重畫。

三套原生網頁簡報共 23 頁（8／7／8），採 16:9 畫布、縮圖、全螢幕、鍵盤與觸控切頁、大字講稿及逐頁來源對照。朗讀讀完本頁才換頁，提供暫停、繼續與停止。使用者提供的是文稿，沒有收到原始 PPTX；本版本明確標示為重製，未宣稱還原原始版型。醫學來源與產品原料完整保留，展示文字區分研究機轉和成品療效。

採 design-taste-frontend 的 app-screen 原則，重視操作層級、可讀狀態與實際瀏覽器驗證。技能的 draw／inspect 腳本資源無法讀取，因此沒有虛構抽選方向或種子；以 Playwright、axe 與實際截圖進行評閱。插畫為本地原創向量圖，沒有虛構產品包裝、講師照片或外部攝影素材。

本輪評閱修正：手機四主題同時顯示、桌面產品頁籤裁切、小字在半透明背景上的對比、簡報連續鍵盤切頁的焦點流失，以及全螢幕與關閉後的焦點返回。測試使用實際 DOM 矩形確認十二個標籤沒有裁切或重疊，並確認選取前後位置一致。頂欄在 100%／125%／140% 字體維持 48px。

2026-11-14 驗證：Node 與 GitHub Pages 靜態版正式建置通過；TypeScript 與 13 項資料／API／安全邊界測試通過。Chromium 的 1440、768、390 像素流程涵蓋產品、講師、知識館、全部 23 頁、前後頁邊界、朗讀自動切頁與停止、全螢幕、140% 字體與 AI 前端合成 SSE。總覽、AI 對話框與簡報播放器的 axe 檢查零違規。靜態版另驗證子目錄資源、兩種尺寸、簡報、本機文件導覽與不呼叫 API。

真實 Node HTTP 測試發現 Next 的 req.url 可能帶 0.0.0.0 綁定位址，原本同源比較誤擋正常瀏覽器。改用 incoming Host 與代理傳輸協定驗證，保留外站請求拒絕；新增 wildcard bind 與 HTTPS 代理回歸測試。
