## 驗證方式

- `npm test`：原始 PDF、297 頁影像、429 張內嵌圖片的雜湊與連結；四主題及十二產品的完整映射；圖解 API 輸入約束。
- `npm run test:visuals`：1440、768、390 像素完整互動、所有 9 份簡報首末頁、12 抽屜、三幕故事、語音契約、放大、PDF.js 即時繪製、故障圖片備援與 axe。
- Node 與 GitHub Pages 分別建置；`verify-longevity-export.mjs` 驗證所有公開原圖與 PDF，不再使用舊的禁止原檔規則。
- 即時 AI 使用真實 Gemini 3.8 Flash，輸入僅為指定原頁與通用圖解主題，不傳送個人健康問題給搜尋。沒有引用時明示未取得即時搜尋來源。

60fps 與語音實際播放仍取決於裝置與瀏覽器；測試使用軟體 WebGL Chromium，沒有冒充實體 iPad 或手機的效能量測。
